Latar Belakang Singkat 
Fakultas Teknik dan Informatika (FTI) Universitas Multimedia Nusantara sedang mengembangkan 
Smart Farming Lab sebagai laboratorium pembelajaran dan riset berbasis teknologi. Ruangan 
laboratorium ini akan dilengkapi dengan prototipe sistem hidroponik yang memerlukan pemantauan 
kondisi lingkungan dan kualitas air secara real-time. 
Untuk mendukung konsep smart system, diperlukan pengembangan sistem monitoring berbasis 
Internet of Things (IoT) yang mampu mengakuisisi data dari berbagai sensor, mengirimkan data ke 
server/cloud, dan menampilkan hasil monitoring secara langsung melalui monitor TV di dalam 
laboratorium. 
Sistem ini diharapkan menjadi fondasi ekosistem Smart Farming FTI yang dapat dikembangkan lebih 
lanjut untuk riset, pembelajaran, dan integrasi kecerdasan buatan pada tahap berikutnya. 
Tujuan Magang (16 Minggu) 
Kegiatan magang selama 16 minggu ini bertujuan untuk merancang dan mengimplementasikan sistem 
monitoring sensor berbasis IoT pada Smart Farming Lab FTI UMN, yang mampu mengukur, 
mengirimkan, dan menampilkan data kondisi lingkungan dan sistem hidroponik secara real-time. 
Secara khusus, tujuan magang ini meliputi: 
1. Mengintegrasikan sensor-sensor lingkungan dan air, meliputi: 
o Sensor suhu 
o Sensor kelembaban udara 
o Sensor kadar oksigen 
o Sensor kadar karbon dioksida (CO₂) 
o Sensor kecepatan aliran air 
o Sensor kadar mineral/EC air 
o Sensor intensitas cahaya 
2. Mengembangkan sistem akuisisi data menggunakan mikrokontroler atau perangkat IoT yang 
sesuai. 
3. Mengimplementasikan pengiriman data berbasis IoT ke server lokal. 
4. Mengembangkan dashboard monitoring yang dapat ditampilkan pada monitor TV di dalam 
laboratorium. 
5. Menghasilkan sistem monitoring IoT yang stabil dan siap digunakan sebagai media 
pembelajaran dan demonstrasi. 
Metode Pelaksanaan Magang 
Pelaksanaan magang dilakukan secara iteratif melalui tahapan berikut: 
1. Analisis kebutuhan teknis laboratorium. Mengidentifikasi kebutuhan sensor, spesifikasi teknis 
ruangan, sumber daya listrik, dan infrastruktur jaringan. 
2. Perancangan arsitektur sistem IoT. Menyusun arsitektur sistem mulai dari sensor → 
mikrokontroler → gateway → server/cloud → dashboard display. 
3. Instalasi dan kalibrasi sensor. Memasang sensor di sistem hidroponik dan melakukan 
pengujian awal serta kalibrasi. 
4. Pengembangan sistem akuisisi dan transmisi data. Mengembangkan program mikrokontroler 
untuk membaca sensor dan mengirimkan data ke server. 
5. Pengembangan dashboard monitoring. Membangun dashboard visualisasi data real-time 
untuk ditampilkan pada monitor TV laboratorium. 
6. Uji coba, evaluasi, dan penyempurnaan. Melakukan pengujian sistem secara keseluruhan dan 
perbaikan stabilitas sistem. 
7. Dokumentasi dan pelaporan. Menyusun dokumentasi teknis sistem serta laporan magang. 
Target dan Capaian Mingguan (16 Minggu) 
Minggu 1–2 | Analisis & Perencanaan 
 Identifikasi kebutuhan sensor dan spesifikasi teknis. 
 Studi literatur singkat terkait sensor dan IoT platform. 
 Penyusunan arsitektur sistem awal. 
Output: Dokumen arsitektur sistem IoT Smart Farming. 
Minggu 3–4 | Desain & Persiapan Perangkat 
 Pemilihan mikrokontroler (misalnya ESP32/Arduino). 
 Desain skema koneksi sensor.

Minggu 5–7 | Instalasi & Akuisisi Data Sensor 
 Instalasi sensor di sistem hidroponik. 
 Pengujian pembacaan sensor. 
 Kalibrasi dasar sensor. 
Output: Sistem pembacaan sensor lokal berjalan stabil. 
Minggu 8–10 | Implementasi IoT Data Transmission 
 Implementasi pengiriman data ke server/cloud. 
 Pengujian stabilitas jaringan. 
 Logging data awal. 
Output: Data sensor terkirim secara real-time. 
Minggu 11–12 | Pengembangan Dashboard Monitoring 
 Pembuatan dashboard visual (grafik, indikator numerik).

 Tampilan real-time update. 
Output: Dashboard monitoring versi MVP. 
Minggu 13–14 | Integrasi & Uji Coba Sistem 
 Integrasi seluruh sistem sensor–IoT–dashboard. 
 Pengujian stabilitas jangka waktu tertentu. 
 Perbaikan bug. 
Output: Sistem IoT terintegrasi versi Beta. 
Minggu 15–16 | Dokumentasi & Serah Terima

 Penyusunan laporan magang. 
 Presentasi hasil di Smart Farming Lab.
