Melakukan diskusi lanjutan terkait arsitektur sistem. Pada tahap ini diputuskan untuk mengubah pendekatan dari arsitektur master–slave menjadi arsitektur langsung (direct connection), di mana setiap ESP32 akan terhubung ke WiFi dan langsung publish data ke MQTT broker.


Alasan perubahan:


               * Lebih sederhana
               * Tidak bergantung pada satu node master
               * Lebih scalable untuk penambahan device ke depannya


David: Saya terlibat dalam diskusi strategis mengenai desain sistem komunikasi IoT, di mana diputuskan untuk beralih dari model master-slave ke arsitektur direct connection guna menyederhanakan alur data dari ESP32 menuju backend. Melalui pendekatan ini, saya mengoptimalkan sisi server agar dapat menangani koneksi langsung dari setiap perangkat ke MQTT broker via WiFi, yang bertujuan untuk menghilangkan ketergantungan pada satu titik kegagalan (single point of failure) dan meningkatkan skalabilitas infrastruktur saat terjadi penambahan perangkat di masa depan.
